  FAT-P StateMachine Benchmark Suite

Configuration:
  Seed:           12345
  Warmup runs:    3
  Measured runs:  15
  Target work:    5000000 ops/batch
  Min batch ms:   50
  Scope:          ON
  Stabilize:      ON
  Cooldown:       ON

Design invariants:
  1. Each measured run executes exactly one timed iteration per library
  2. Library execution order is randomized per run (round-robin)
  3. Setup/teardown occur outside timed regions
  4. All libraries observe the same distribution of machine states
  5. Medians are the primary reported statistic

Competitors (tested in ALL applicable sections):
  - fat_p::StateMachine<AnyToAnyTransitionPolicy>
  - fat_p::StateMachine<StrictTransitionPolicy>
  - Manual enum-switch state machine
  - Manual function-pointer table state machine
  - std::variant + std::visit (C++17 standard baseline)
  - [Boost::ext].SML (header-only)
  - Boost.MSM (full Boost)
  - TinyFSM (header-only)
