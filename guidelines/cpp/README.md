# C++ entry point

The C++ guides bind automatically for C++ work. C++20 is the minimum; no C++17
fallback or syntax-emulation macros. Read the relevant routes in [CORE](../CORE.md).

Project facts have one home: [PROJECT_PROFILE](../PROJECT_PROFILE.md). They do
not waive [STYLE](STYLE.md). This guide set covers header-only and compiled code,
public/internal APIs, tests, examples, named modules and binary boundaries.

The normative pages are [Authoring](AUTHORING.md), [Headers and linkage](HEADERS_AND_LINKAGE.md),
[Testing](TESTING.md), [Build and CI](BUILD_AND_CI.md), and [Documentation](DOCUMENTATION.md).
