# Results folder

Drop benchmark outputs here (console logs, CSV exports, flamegraphs, VTune screenshots, etc.).

Suggested naming:
- `YYYY-MM-DD_core_N1e6.txt`
- `YYYY-MM-DD_missdiag_optionB_N1e6.txt`
- `YYYY-MM-DD_perf_etw_find_miss.etl`

This keeps the *story* (docs/) separate from the *evidence* (results/).
