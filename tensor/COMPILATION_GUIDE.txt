## Compilation Commands

### Without MKL (Default Backend Only)

```bash
# Compile simple test
g++ -std=c++17 -O2 -Wall -Wextra -I. \
    simple_backend_test.cpp -pthread \
    -o simple_backend_test

# Run
./simple_backend_test
```

### With MKL (Full Optimization)

```bash
# Set MKL environment
source /opt/intel/oneapi/setvars.sh

# Compile with MKL
g++ -std=c++17 -O2 -Wall -Wextra \
    -DCPP_UTILITIES_USE_MKL=1 \
    -I. \
    -I${MKLROOT}/include \
    simple_backend_test.cpp \
    -pthread \
    -L${MKLROOT}/lib/intel64 \
    -lmkl_intel_lp64 -lmkl_sequential -lmkl_core \
    -lpthread -lm -ldl \
    -o simple_backend_test

# Run with MKL optimizations
./simple_backend_test
```

## Common Issues and Solutions

### Issue 1: Header Not Found
```
error: TensorWithBackend.h: No such file or directory
```
**Solution**: Ensure all headers in same directory
```bash
cp /mnt/project/*.h .
cp Tensor*.h .
```

### Issue 2: MKL Headers Missing
```
error: mkl.h: No such file or directory
```
**Solution**: Either:
- Install MKL: `source /opt/intel/oneapi/setvars.sh`
- Or compile without: Don't define `CPP_UTILITIES_USE_MKL`

### Issue 3: Linking Errors
```
undefined reference to `cblas_dgemm'
```
**Solution**: Link MKL libraries:
```bash
-lmkl_intel_lp64 -lmkl_sequential -lmkl_core -lpthread -lm -ldl
```

### Issue 4: Template Errors
```
error: no matching function for call to 'matmul'
```
**Solution**: Check that backend supports the type:
```cpp
static_assert(backend_supports_type_v<MKLBackendPolicy, double>);
```
