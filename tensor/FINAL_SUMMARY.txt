### Basic Usage

```cpp
#include "TensorWithBackend.h"

int main() {
    using namespace cpp_utilities;
    
    // Option 1: Explicit backend selection
    TensorWithBackend<double, StandardAllocatorImpl<double>,
                      SingleThreadedPolicy, MKLBackendPolicy>
        tensor(TensorShape({1000, 1000}), 1.0);
    
    // Option 2: Convenient alias (recommended)
    TensorDoubleMKL A(TensorShape({1000, 1000}), 1.0);
    TensorDoubleMKL B(TensorShape({1000, 1000}), 2.0);
    
    // Matrix multiply - automatically uses best backend
    auto C = A.matmul(B);
    
    return 0;
}
```

## 🎯 Key Features Verified

### ✅ Policy-Based Design
- Backend is now a **first-class template parameter**
- Pure policy-based (no inheritance needed for dispatch)
- Consistent with library's AllocationStrategy, ConcurrencyPolicies

### ✅ Zero-Overhead Abstraction
- All backend selection at **compile time**
- `if constexpr` for branch elimination
- No virtual functions, no runtime dispatch
- Binary size identical to hand-written code

### ✅ Type Safety
- Compile-time checking: `backend_supports_type_v<Backend, T>`
- Automatic fallback for unsupported types
- SFINAE prevents incorrect usage

### ✅ Graceful Degradation
- Works perfectly without MKL installed
- MKLBackendPolicy compiles even when MKL unavailable
- Automatic fallback to default implementation
- No #ifdef needed in user code

### ✅ Extensibility
- Easy to add new backends (CUDA, OpenBLAS, Eigen, etc.)
- Backend policies are just static methods
- No framework overhead

## 🎓 Architecture Highlights

### Policy Composition
```cpp
TensorWithBackend<
    T,                           // Element type
    AllocationStrategy,          // Memory management policy
    ConcurrencyPolicy,           // Thread-safety policy
    BackendPolicy                // Computation backend policy
>
```

All four dimensions are **pure policies**!

### Type Trait System
```cpp
backend_supports_type_v<Backend, T>  // Compile-time check
has_matmul_v<Backend>                // Operation availability
```

### Automatic Dispatch
```cpp
if constexpr (backend_supports_type_v<BackendPolicy, T>) {
    return matmul_backend(other);    // Optimized path
} else {
    return matmul_default(other);    // Fallback path
}
```
